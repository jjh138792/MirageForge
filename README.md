## 🎯 它能帮我做什么？

简单来说，它可以在**不改系统分区、不影响其他正常软件**的前提下，单独让指定的游戏或应用以为你的手机是另一台设备：

### 1. 解锁游戏高帧率、高画质与 HDR 显示
* **机型 + 显卡同步伪装**：不少游戏不仅看手机型号，还会顺手查显卡型号。模块支持同时伪装机型和 OpenGL / Vulkan 显卡名称，配合屏幕最高刷新率（90Hz / 120Hz / 144Hz / 165Hz）与可选的 **HDR / 杜比视界**能力声明，方便开启游戏和影音软件内置的高帧率与高画质档位。
* **一键场景预设**：懒得一个个调开关？应用编辑页顶部直接提供了 **「极致隐匿」「游戏高刷」「全量伪装」** 三个预设，点一下就能套用。

### 2. 从头到脚的整机信息伪装
不只是改个手机型号，硬件检测软件常看的细节也能一起配齐：
* **系统与机型信息**：品牌、型号、代号、处理器型号、安全补丁日期、完整指纹，以及跨品牌的专属系统字段（比如在类原生上伪装澎湃 OS 或 OriginOS 的部分特征）。
* **CPU 与动态频率**：处理器名称、核心数以及每颗核心的频率都能自定义，运行起来频率还会像真机一样自然跳动，不会死板卡死在同一个数字。
* **运行内存（RAM）**：同时伪装物理内存规格（如 `16GB LPDDR5X`、`24GB LPDDR5T`）与系统总内存、可用内存大小。

### 3. 更省心的模板管理与新应用自动托管
* **多种方式拿到模板**：内置常见旗舰预设，支持拉取**在线模板库**、用 `mf://` 分享码互传模板、导入现成的 `build.prop` 自动解析，甚至可以**一键克隆自己当前手机的硬件配置**。
* **单应用微调（局部覆写）**：只想把某一个软件的内存改大一点，或者多加两条属性？直接在应用页底部填写局部覆写就行，不用为了微调一个数字专门复制一套新模板。
* **新装应用自动加入伪装**：在设置里开启后，新安装的用户应用会自动套上你选好的默认模板，同时内置保护名单自动跳过 Root 管理器和常用终端工具，不用每次装完软件再手动勾选。

### 4. 按需开关，不用的功能绝不插手
* **细粒度独立开关**：每个应用都可以单独决定是否伪装「系统属性」「CPU」「GPU」「内存」「CPU/GPU 文件节点」。**没配置伪装的应用，或没打开的子项，模块都不会去碰它**，尽量不拖慢日常启动。
* **多种属性工作模式**：在应用编辑页对着「伪装系统属性」**双击或长按**，可以按需切换更兼容的传统模式或更隐蔽的无 Hook 模式，并在应用列表里直接看到上次启动的实际生效状态。
* **默认保护防闪退**：默认保留手机原本的 Android 版本号，避免跨大版本导致闪退；确有需要也可以单独开启。

### 5. 自带排障探针
遇到某个软件伪装后还是识别不对，可以单独给它开一下 **「探针与调用栈」** 开关，打开软件跑几秒再回来，就能看到它刚刚查了哪些属性和文件；发现模板里漏掉的冷门属性，点一下 **「+ 捕获入库」** 就能补进去。排障完记得关掉即可。

## 🚀 安装与使用

### 1. 环境要求
* **系统版本**：Android 8.0 (API 26) ~ Android 17 (API 37)
* **Root 与 Zygisk 环境**：
  * **Magisk** (v26.0+)：开启内置 Zygisk，或搭配 **Zygisk Next / ReZygisk**
  * **KernelSU / KernelSU Next / APatch**：需配合安装 **Zygisk Next** 或 **ReZygisk**
* **刷入方式**：在 Root 管理器内直接刷入模块 ZIP 并重启生效。

### 2. WebUI 面板操作（推荐）
重启后在 **KernelSU / APatch / MMRL / KSUWebUI** 中点开「蜃楼工坊 · MirageForge」即可使用（支持浅色/深色自动切换、5 套强调色、简/繁/英三语、左右滑屏切页与模块在线更新）：
1. **首页**：查看当前设备与 Root/Zygisk 环境信息、已生效统计以及在线更新提示。
2. **模板**：管理硬件模板，支持在线拉取、导入 `build.prop`、`mf://` 分享码导入导出以及一键克隆本机。
3. **应用**：点进目标应用选好模板，按需勾选能力开关（对着「伪装系统属性」双击或长按可切换底层模式），点击右上角 ⚡ 重启应用即刻生效。
4. **设置**：调整界面外观、全局默认引擎、开启「新安装应用自动加入伪装」、进入幻境探针或一键导出诊断包。

### 3. 命令行与高级配置
如果你习惯用终端、脚本批量管理，或者想了解配置文件的具体格式与各引擎模式的区别，请查阅专门的配置文档：
